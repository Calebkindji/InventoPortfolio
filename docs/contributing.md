# Contribution

1. Cloner le dépôt.
2. Créer une branche depuis `develop`.
3. Développer une seule fonctionnalité par branche.
4. Tester localement.
5. Faire un commit clair.
6. Ouvrir une Pull Request vers `develop`.

Exemples :
- `feature/authentication`
- `feature/profile`
- `feature/projects`
- `fix/login-validation`

Convention de commit recommandée :

- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `docs:` documentation
- `refactor:` refactorisation
- `test:` tests
- `chore:` maintenance
